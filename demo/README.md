# Demo evidence

`public-feed-fetch-only.json` is a real CanvasPilot run with the agent tasks switched off and a public New Zealand holidays .ics feed in place of a Canvas calendar feed, to show the TinyFish Fetch path and the merge/export logic without exposing a real student account. The app never reads this folder.

The signed-in Canvas run is shown in the video demo with personal details blurred.
